# Brand Identity & Voice Guidelines

## Communication Philosophy
* **Bottom Line Up Front (BLUF)**: State the verdict and evidence immediately. No corporate pleasantries or throat-clearing preambles.
* **Builder-to-Builder Tone**: Write from the perspective of an engineer building tools for engineers. Pragmatic, honest, zero marketing hype.
* **Kill List**: Never use words like *revolutionary, seamless, holistic, supercharge, game-changing, delve, tapestry*. Replace every buzzword with the concrete technical mechanism or exact metric.

## Visual Design Standards
* **Color Palette**: Happy Hues #17
  * Background: Cream (`#fef6e4`)
  * Primary Text / Headings: Navy (`#001858`)
  * Accent 1: Pink (`#f582ae`)
  * Accent 2: Teal (`#8bd3dd`)
* **Assets**: High-contrast, clean SVG graphics, minimalist data tables, and reproducible diagrams.
