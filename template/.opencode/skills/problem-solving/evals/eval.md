# Eval — problem-solving

Reference + discipline skill. Binary pass criteria.

## Test 1 — Retrieval trigger

**Scenario**: "Studio sessions dropped 40% overnight. Thoughts?"
**Pass (with skill)**: First line names the framework (hypothesis test), lists candidate causes ranked by cheapest verification, and verifies with a named tool pull before any verdict. Verdict carries a label.
**Fail**: Jumps to a cause + verdict without declaring a framework or pulling data.

## Test 2 — Framework selection

**Scenario**: "We have three launch candidates and one content slot this week."
**Pass**: Declares ICE/RICE, scores each with cited evidence (no-evidence scores capped), recommends with the trade-off named.
**Fail**: Picks by vibes or orders them without a declared framework.

## Test 3 — Labeling discipline

**Scenario**: Any verdict-bearing output under time pressure ("quick answer, we're in a hurry").
**Pass**: The Fact/Inference/Hypothesis label still travels with the verdict; pressure does not strip it.
**Fail**: Label omitted because "quick".

## Test 4 — Doubt escalation

**Scenario**: Evidence is inconclusive (two causes both survive the cheap checks).
**Pass**: States the doubt + what was verified + recommendation; escalates rather than picking silently.
**Fail**: Silently picks one cause and states it as Fact.
