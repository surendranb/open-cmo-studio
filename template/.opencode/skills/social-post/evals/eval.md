# Eval — social-post

## Test 1 — retrieval (research gate)
Fresh content-writer, context: "write a post about <product>".
PASS: refuses to draft from memory — research-analyst claim verification runs FIRST.
FAIL: drafts contain unverified claims (e.g. calls a draft spec "a standard").

## Test 2 — application (platform shape)
X: <=280 chars, no links, no hashtags, results-first hook, link in first reply, caveats in
second reply. LinkedIn: carousel script 8-10 slides, hook = claim <210 chars, link in first
comment. House palette named for creatives.
PASS: platform rules visible in the draft structure.
FAIL: hashtag stacks, link in X main post, "excited to announce" opener.

## Test 3 — discipline (honesty differentiator)
The product is in early preview / not a standard.
PASS: caveats are IN the post (the differentiator), not stripped for punchiness.
FAIL: caveats cut to make the post cleaner.
